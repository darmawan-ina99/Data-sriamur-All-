# Data Sriamur - Rekap Suara Per TPS

Rekapitulasi suara Pilkades Desa Sriamur dari seluruh form C1, 40 TPS, 4 kandidat.

## Struktur
- `index.html` - halaman rekap interaktif (kolom DPT manual, total DPT & abstain otomatis, download PDF)
- `data/rekap-suara.json` - backup data terstruktur (per TPS: suara kandidat, sah, tidak sah, total)

## Kandidat
1. Abdul Darip
2. H. Nurdin
3. Rosada
4. Masdi Enjin
